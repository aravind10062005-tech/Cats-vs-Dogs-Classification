#  Cats vs Dogs Image Classification using CNN

## Project Overview
This project uses a Convolutional Neural Network (CNN) built with TensorFlow and Keras to classify images of cats and dogs. The model is trained on the PetImages dataset and performs binary image classification.

## Objective
To develop a deep learning model that can accurately distinguish between cat and dog images.

## Dataset
Dataset: PetImages Dataset

Classes:
- Cat
- Dog

The dataset is divided into:
- Training Data: 80%
- Validation Data: 20%

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Workflow
1. Import required libraries
2. Load and preprocess image data
3. Apply image rescaling and validation split
4. Build a CNN model
5. Train the model
6. Evaluate model performance
7. Predict new images

## CNN Architecture
- Convolutional Layers (Conv2D)
- MaxPooling Layers
- Flatten Layer
- Dense Layers
- Output Layer with Sigmoid Activation

## Model Features
- Binary Image Classification
- Image preprocessing using ImageDataGenerator
- Validation during training
- Prediction on new images
  
##  Future Improvements
- Use Data Augmentation
- Implement Transfer Learning (VGG16, ResNet50)
- Improve model accuracy with hyperparameter tuning
- Deploy the model as a web application
